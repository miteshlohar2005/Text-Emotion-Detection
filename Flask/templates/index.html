System Overview

EmotionAI is a technical text classification platform engineered to detect affective states from unstructured natural language inputs.

The system evaluates sequence tokens against learned semantic representations to predict emotional valence across five core target classes: Joy, Sadness, Anger, Love, and Fear.

Designed with a strict monochrome engineering aesthetic, this workspace prioritizes computational transparency, probability distributions, and continuous latent space telemetry.

Inference Pipeline

The NLP pipeline executes through five distinct computational stages:

  • STAGE 01 Regex Sanitization & Lowercasing
  • STAGE 02 NLTK Word Tokenization
  • STAGE 03 Stopwords & WordNet Lemmatization
  • STAGE 04 Keras Post-Padding (Max Len = 35)
  • STAGE 05 Recurrent LSTM & Softmax Activation

Model Specifications

Architecture parameters extracted from the trained serialization artifacts:

  • FRAMEWORK TensorFlow / Keras
  • NETWORK TYPE LSTM (Long Short-Term Memory)
  • SEQUENCE LENGTH 35 Timesteps (Post-padded)
  • TARGET CLASSES 5 (Anger, Fear, Joy, Love, Sadness)
  • ACTIVATION Softmax Probability Distribution
  • TOKENIZER ENCODING Pickle Word Tokenizer
